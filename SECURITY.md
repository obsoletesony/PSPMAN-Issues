# Security and privacy reports

Do not post security or privacy details, private diagnostic logs, passwords, account information, or copyrighted music in a public GitHub issue.

For a private PSPMAN security or privacy report, email **obsoletesony@gmail.com** with the subject **PSPMAN private report**. Include the PSPMAN version and a short description of the problem. Do not attach music files or a complete PSP storage dump.

For ordinary bugs, compatibility results, help, and feature requests, use the public issue forms instead.
