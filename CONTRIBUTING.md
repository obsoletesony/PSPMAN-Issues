# Reporting and contribution guide

This repository is the public support tracker for PSPMAN. It does not contain PSPMAN's application source code.

## The easiest way to help

Use the guided forms under [New issue](https://github.com/obsoletesony/PSPMAN-Issues/issues/new/choose):

- Report a PSPMAN problem
- Report a problem in Japanese
- Share a compatibility result
- Ask for help
- Suggest an improvement

No technical experience is required. Incomplete but honest information is more useful than a report that was never submitted.

## Good bug reports

A useful report usually contains:

1. PSP model
2. System software or custom firmware
3. PSPMAN version
4. What happened
5. Steps leading to the problem
6. Whether it happens repeatedly
7. `PSPMAN-HW-DIAG.log`, when available

The diagnostic log is at the root of the Memory Stick beside the `PSP` folder. Copy it before launching PSPMAN again because the next launch replaces it.

Do not change or convert the affected song before reporting. Replacing its metadata or cover can remove the condition that caused the problem.

## Public information

Issues, comments, and attachments in this repository are public. Review every file before uploading it.

Do not upload copyrighted music, complete Memory Stick contents, passwords, account information, or anything else you do not want publicly accessible.

## Language

Reports in English or Japanese are welcome. Reports in other languages are also accepted; use the English form and write in the language you are most comfortable using.

## Source-code contributions

PSPMAN's source repository is private during the current development stage, so this repository does not accept application code changes. Pull requests here should be limited to corrections or improvements to the public reporting system and documentation.
